# Módulo: Segurança Ofensiva, Defensiva e DevSecOps em Python

Projetos em Python cobrindo criptografia avançada, gestão de chaves Vault, scanners de vulnerabilidades, auditoria de APIs, honeypots e análise forense.

Este módulo contém 20 projetos práticos de nível sênior baseados na vida real corporativa (SRE, Platform Engineering, DevOps e Infraestrutura em Nuvem).
